MACHINE LEARNING LAB EXPERIMENTS - PYTHON
==========================================

This package contains 22 experiments. Each experiment has its own folder.
Every experiment folder contains:
- One Python source file
- A README.txt with the experiment aim, requirements, and run instructions

SETUP
-----
1. Extract this ZIP file.
2. Open a terminal in the extracted ML_Lab_Experiments folder.
3. Install the required libraries:

   pip install -r requirements.txt

4. Open the folder for the experiment you want to run.
5. Run its Python file using the command shown in that folder's README.txt.

Example:
   cd 01_Data_Preprocessing
   python 01_data_preprocessing.py

NOTES
-----
- Run one experiment at a time.
- Run commands from the experiment folder, or provide the relative path to the script.
- Most experiments use datasets included with scikit-learn.
- Experiments 3 and 4 create sample Pandas DataFrames.
- Experiment 19 uses a built-in mathematical optimization example.
- Experiment 20 uses a small custom GridWorld environment.
- Plot-based experiments open Matplotlib windows.
