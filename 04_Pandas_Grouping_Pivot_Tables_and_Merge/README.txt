PANDAS GROUPING, PIVOT TABLES, AND MERGE
========================================

Experiment number: 4
Python file: 04_pandas_groupby_pivot_merge.py

AIM
---
Run the Python program to perform the pandas grouping, pivot tables, and merge experiment.

REQUIREMENTS
------------
- Python 3.9 or newer
- numpy
- pandas
- matplotlib
- scikit-learn

HOW TO RUN
----------
1. Make sure you have extracted the complete ZIP package.
2. Open a terminal in this experiment folder.
3. Install the libraries if you have not already installed them:

   pip install -r ../requirements.txt

   If you are running this folder separately, use:

   pip install numpy pandas matplotlib scikit-learn

4. Run the Python program:

   python 04_pandas_groupby_pivot_merge.py

OUTPUT
------
The program prints its results in the terminal.
If the experiment includes visualizations, Matplotlib opens a plot window.
